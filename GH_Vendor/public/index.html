{code} = mã đơn hàng. Ngày để trống = hôm nay. Không chọn tệp thì tool tự tạo 1 file PDF test.

Tool mở 1 cửa sổ trình duyệt và tự thao tác: Quản lý NCU → Giao hàng, triển khai NCU → tab Quản lý phiếu giao hàng → dấu tích: Chưa giao hàng → Đang giao hàng (điền hoá đơn) → Đã hoàn tất. Hệ thống tải chậm, mỗi phiếu mất vài phút. Chạy lại cùng mã sẽ tiếp tục từ tình trạng hiện tại.
